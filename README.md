# Segundo Cérebro Python 🐍

## Sobre o projeto

Este projeto utiliza o Gemini Notebook como um segundo cérebro de estudos para aprender Python do zero à prática. O objetivo é organizar fontes de aprendizagem, esclarecer conceitos, praticar programação e criar materiais de revisão com o apoio da inteligência artificial.

## Objetivo

Construir uma base de conhecimentos para iniciantes em Python, com explicações simples, exemplos de código, exercícios progressivos e materiais de estudo fundamentados nas fontes selecionadas.

## Ferramentas utilizadas

- **Gemini Notebook:** organização das fontes e apoio ao aprendizado com IA.
- **GitHub:** documentação e armazenamento público do projeto.
- **Python:** linguagem de programação estudada.

## Fontes de estudo

- [Curso em Vídeo — Python 3: Mundo 1](https://www.cursoemvideo.com/curso/python-3-mundo-1/)
- [Microsoft Learn — Fundamentos de Python](https://learn.microsoft.com/en-us/training/paths/get-started-with-python-fundamentals/)
- [Tutorial oficial do Python em português](https://docs.python.org/pt-br/3/tutorial/)
- [Python.org — Getting Started](https://www.python.org/about/gettingstarted/)

As fontes foram selecionadas para apoiar o aprendizado dos fundamentos da linguagem, combinando conteúdo introdutório com documentação oficial.

## Testes realizados

Foram realizadas consultas ao Gemini Notebook para avaliar sua utilidade como ferramenta de estudo:

1. **Variáveis em Python:** explicação do conceito com exemplo e citações.
2. **`input()` e `print()`:** comparação entre entrada e saída de dados, com exemplo comentado.
3. **`input()` e `int()`:** explicação da conversão de texto para número e do erro que pode ocorrer sem conversão.

As respostas foram úteis para o estudo inicial. As citações devem ser verificadas em relação ao conteúdo exato das fontes.
